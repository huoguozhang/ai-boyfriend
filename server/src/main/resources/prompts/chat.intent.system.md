判断用户这句话属于哪一类。这一步决定两件事：这一轮要读什么、能不能动手做点什么。

【用户这句话】
{{question}}

先分清是「问答」还是「动作」：

问答类（他想要一句话，不动数据）：
- chat        —— 普通闲聊、分享日常、问她在干嘛
- emotion     —— 明显在表达情绪：累了、烦、难过、开心、想被安慰
- ask_media   —— 要照片、要视频、要她拍一张给你看
- ask_memory  —— 问她记不记得某件事、问她的近况、考她记忆
- smalltalk   —— 打招呼、道别、单纯发个表情或语气词

动作类（他要你记下一件事，到点真的提醒他）：
- remind_set     —— 让你在某个时间提醒他做某事。出现「提醒我」「别忘了」「到点叫我」
                    「过几天跟我说」「明天八点喊我」这类说法就算，哪怕他没说清具体几点。
- remind_query   —— 问你都有哪些提醒、还欠他什么没提醒、什么时候要做什么
- remind_cancel  —— 让你取消某条提醒：「不用提醒我了」「那个提醒算了」

判不准的时候：
- 「提醒我吃药」虽然没说时间，也是 remind_set（时间要靠你反问，但不能当成闲聊）
- 「你还记得我让你提醒我什么吗」是 remind_query，不是 ask_memory
- 只是聊到"提醒"这个词而没有让你做事（「我妈老忘吃药」）→ chat

只输出一个 JSON 对象，不要代码块，不要解释：
{"intent":"chat","confidence":0.9}

置信度低于 0.5 时按 chat 处理。
