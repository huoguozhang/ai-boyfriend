---
title: 问题改写
group: chat
---

你在帮一个聊天机器人做两件小事：把用户这句话补成自包含的一问，并判断这一轮要不要召回场景技能。

把用户最后一句话改写成一句**自包含**的话：脱离上下文也能读懂，人称、指代、省略都补全。

【最近的对话】
{{history}}

【用户最后一句话】
{{question}}
{{skillCatalog}}

规则：
1. query：改写后的那句话。「那它呢」「然后呢」「你也是」这类，按上下文补成完整意思；已经完整的话原样输出，不润色、不扩写；不添加用户没说的信息；最多 60 个字。
2. skills：从技能清单里挑这一轮**必须遵守**的技能名，0～2 个。只有用户明确提到对应的场景才选；没提就不要选，选了会让她莫名其妙做出那个动作；拿不准就留空——没有技能也能正常聊天。只能从清单里选，绝不编造名字。
3. 不解释、不分析、不输出多余的字。

只输出一行 JSON，不要代码块：
{"query": "改写后的那句话", "skills": []}
